# The Book

**Start here: `00_THE_BOOK.md`.**

This is the thing a person reads. One text, beginning to end, no jargon, no
cross-references, no need to know anything before starting.

Everything else in this repository — the chapters, the nodes, the sector
briefs, the platform documents — is the **evidence behind the book**. A
reader never has to open any of it. A skeptic can open all of it.

## Why this exists

The project spent a long time building evidence and organised it the way
researchers organise things: by node, by chapter, by sector. That is useful
for checking and useless for reading. A stranger landing here had no idea
where to start or where to stop.

So: one book. Six parts. Real people and real situations, not concepts.
Every technical term we invented — "absorptive capacity," "stock and flow,"
"route-matching" — is banned from these pages. If an idea cannot be said in
ordinary language, it does not go in.

## The rules this text obeys

1. **A real person or a real thing in the first line of every chapter.** Not
   an idea.
2. **No invented vocabulary.** Say "the money leaks before it arrives," not
   "collection integrity failure."
3. **Every number is checkable, and the source is named in plain language**
   at the end of the section, not in a footnote.
4. **Every weakness in our own evidence is stated by us, in the same
   chapter**, not hidden in an appendix.
5. **Short chapters.** A person should be able to finish one while waiting
   for something.
6. **Pidgin version to follow, written fresh** — not translated from the
   English, because translated Pidgin always sounds translated.
