# Research Engine — Version History

A commit log for the methodology. Every entry ties a change to the investigation
that earned it. This file is how the engine proves it is self-improving from
evidence rather than drifting on cleverness.

## v0.1 — first commit (origin: Node 1, Revenue Structure)

The engine's birth. Deliberately tiny. Everything here traces to one completed
investigation; nothing is speculative.

**Added:**
- `PREAMBLE.md` — highest principle (discover what is true, not prove what we believe).
- `LAW_ZERO.md` — no rule without a named case; the anti-warehouse tripwire.
- `Skills/Comparative_Statecraft_Engine.md` (v0.1) — Rules 1–3:
  confounded cases, IGR classification, audit-over-advocacy.
- `Evidence_Standard.md` (v0.1) — Certified / Contested / Confounded / Owed.
- `SOPs/Investigation_SOP.md` (v0.1) — the 7-step node sequence.
- `Lessons Learned/Mistakes.md` — Node 1 entries 1.1–1.3 and meta-mistake 1.0.

**Node 1 status at this commit:**
- *Certified:* dependence problem (30 states at 71–92% FAAC reliance).
- *Confounded:* Lagos.
- *Contested:* Osun.
- *Owed:* Enugu (independent confirmation of automation/compliance + capital execution).

**Honest flag on this commit.** The Comparative Statecraft Engine is named as a
"skill" but currently holds three rules, not a mature capability. That is correct
for v0.1 and consistent with Law Zero — it will earn the name as nodes accrue.

## v0.2 — review-earned commit (origin: post–Node 1 review)

A review proposed seven additions. They were sorted by the three-question test
(what problem / which investigation exposed it / could the engine continue
without it). Four passed; three did not and are logged as **Candidates** — which
carry **no obligation to ship**.

**Earned and added:**
- `RESEARCH_HABIT.md` — the three-question test + the four change-types
  (patch/rule/capability/governance). *Type: governance.*
- `Evidence_Standard.md` → v0.2 — added **Rejected** status (*governance*) and the
  **Fact vs. Interpretation** split (*patch*).
- `Skills/Comparative_Statecraft_Engine.md` — standardized **Birth Certificate**
  blocks (*patch*; rules themselves unchanged).
- `Lessons Learned/Assumptions.md` — created with one live entry: the units-first
  bet (*governance*).

**Candidates (NOT roadmap — may be disproven before they are ever earned):**
- **Publication Rule** — protects against Disease B (never publishing). Real, but
  no publishable body exists yet. Trigger: first chapter-length set of claims.
- **Decision.md per node** — facts vs. decisions. Trigger: Node 1 *close* (after
  Enugu), when there is an actual decision to record.
- **"Strong" evidence status** — no current claim needs a tier between Contested
  and Certified. Trigger: a claim that genuinely requires it.
- **Semantic versioning (1.0.0)** — ceremony without function until skills have
  downstream dependents. Trigger: first time one skill's rule is relied on by
  another skill.

**Honest note:** v0.2 is entirely patches + governance. No new *capability* (no new
skill) and no new *rule* inside a skill were added — correct, because Node 1's
rules were already banked at v0.1 and no new investigation has run since.

## v0.3 — first evidence-earned commit (origin: Node 1, Enugu certification)

The first engine update paid for by a *new investigation* rather than a review.
Enugu was run as a falsification attempt (search against the thesis, not for it).
The thesis partly failed — which is exactly why this commit matters.

**Earned and added:**
- `Skills/Comparative_Statecraft_Engine.md` → **v0.2**:
  - **Rule 2.1** — decompose revenue by source before classifying (*rule*).
  - **Rule 4** — separate revenue source from the three institutional layers
    (collection integrity / fiscal management / execution) (*rule*).
- `Lessons Learned/Mistakes.md` — entries **1.4** (rejected: "automation drove
  Enugu") and **1.5** (rejected over-correction: "non-tax is suspect").
- `Lessons Learned/Node_1_Decision.md` — first Decision file (*Candidate promoted
  to Earned*). Decision recorded at ~70% confidence.

**Deliberately NOT added (review-disciplined):**
- A rule treating non-tax growth as inherently suspect — *rejected as overreach*;
  it prejudges what decomposition exists to examine. Logged as Mistake 1.5.

**Honest flag:** Node 1 has proven a *mechanism* (the three layers, corroborated)
but not a *transfer* (no ordinary state has yet adopted them from scratch and
succeeded). The Decision records this gap as the still-owed replication proof.
